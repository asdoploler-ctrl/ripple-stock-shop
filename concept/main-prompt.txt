## ТЕХНОЛОГИИ (строго)
- Только HTML5, CSS3 и ванильный JavaScript. Без фреймворков, библиотек, сборщиков, препроцессоров и npm (Tailwind, Bootstrap, jQuery, React, SCSS — запрещены).
- Шрифты — только через Google Fonts (<link>), иконки — простые линейные inline-SVG (stroke="currentColor", stroke-width 1.5, без заливки).
- Код максимально простой, как для новичка: понятные названия классов (по-английски, в стиле БЭМ-лайт: .card, .card__title), без хитрых трюков и сложных селекторов.
- ОБЯЗАТЕЛЬНО комментарии на русском: перед каждой секцией в HTML («<!-- Шапка сайта -->»), перед каждым блоком в CSS («/* ===== Шапка ===== */») и перед каждой функцией в JS (что делает и зачем). Объясняй неочевидные места (clip-path, filter, grid) простыми словами.
- Адаптивность: десктоп (от 1024px), планшет (до 1024px), телефон (до 768px и до 480px). Mobile-friendly: ничего не вылезает за экран, нет горизонтального скролла страницы.

## ДИЗАЙН-СИСТЕМА (общее для всех страниц)
CSS-переменные в :root (и используй только их):
--bg: #0a0a0a; --bg-2: #111; --card: #151515; --line: rgba(255,255,255,0.15); --text: #fff; --muted: #a8a8a8; --radius: 4px (почти без скруглений); --container: 1200px.
- Стиль: тёмный, монохромный, гранж/стритвир. Акцентных цветов НЕТ — только чёрный, белый и серые.
- Контейнер: max-width 1200px, margin 0 auto, боковые отступы 24px (на телефоне 16px).
- Заголовки: Montserrat 800, ЗАГЛАВНЫМИ, letter-spacing чуть положительный (запасной шрифт Unbounded). Hero-заголовок: font-size clamp(40px, 6vw, 72px), line-height 1.05.
- Основной текст: Manrope 400/500, 14–16px, цвет --muted или белый.
- Мелкие надписи (хлебные крошки, подписи, пункты меню): 11–12px, заглавными, letter-spacing 0.15em.
- Рукописные надписи: шрифт Caveat (или Marck Script), белый/серый цвет, font-size 28–48px, поворот transform: rotate(-6deg); рядом иногда маленькая иконка-корона (SVG из 3 зубцов). Это обычный текст, не картинки. Класс .handwritten.
- Кнопки: .btn — прозрачный фон, border 1px solid #fff, текст заглавными 12px, letter-spacing 0.1em, padding 16px 28px, справа SVG-стрелка →. При hover: белый фон, чёрный текст, transition .3s.
- Фото: filter: grayscale(1) brightness(0.8).
- Hero-блоки: фон — hero-bg.jpg (cover, center), поверх тёмный градиент слева направо (linear-gradient(90deg, rgba(10,10,10,.95), rgba(10,10,10,.3))), чтобы текст слева читался.
- «Рваный край» между секциями: у блока ::after/::before высотой 30–40px с clip-path: polygon(...) неровным зубчатым краем цвета фона (сделай одну переиспользуемую CSS-реализацию, класс .torn-edge, и объясни её комментарием).
- «Полароид» (.polaroid): фото с белой/серой тонкой рамкой 6–8px, лёгкий поворот (rotate(-2deg) / rotate(3deg)), тень, сверху полупрозрачный «скотч» (псевдоэлемент: прямоугольник 90×26px, rgba(255,255,255,.25), rotate(-4deg)).
- Появление блоков при скролле: классы .reveal (opacity 0, translateY(20px)) → .reveal.visible; добавляется простым IntersectionObserver в main.js.

## JS (js/main.js, только интерфейс, максимально просто)
Раздели файл на понятные функции с комментариями и вызови их после загрузки страницы (DOMContentLoaded):
1. initBurger() — открытие/закрытие мобильного меню.
2. initReveal() — появление блоков с классом .reveal (IntersectionObserver).
3. initFavorites() — переключение сердечка на карточках (визуально, без сохранения).
4. initCounters() — анимация чисел «В цифрах» (если такие есть на странице).
5. initFaq() — аккордеон вопросов (если есть на странице).
6. initContactForm() — простая проверка формы и вывод сообщения (если форма есть на странице).
Каждая функция сначала проверяет, что нужный элемент есть на странице, и если нет — просто выходит (return), чтобы один main.js работал на всех страницах.

## ТРЕБОВАНИЯ К КАЧЕСТВУ
- Семантика: header, nav, main, section, article (для карточек), footer; заголовки h1 (один на странице) → h2 → h3.
- Ссылки между страницами рабочие (index.html, about.html, contacts.html); иконки-ссылки с aria-label.
- Для переиспользуемых элементов (кнопка, карточка, полароид, рукописная надпись, рваный край) один класс в CSS, а не копии стилей.
- Единый подход к отступам: секции с padding 60–80px по вертикали (на телефоне 40px).
- Не усложняй: если есть простое и сложное решение, выбирай простое. Никаких внешних зависимостей, кроме Google Fonts.
